# Décisions — Foundation 0.1.1

- **Acceptée**: Foundation locale avant Claude Agent SDK, OpenHands ou RAGLite.
- **Acceptée**: Opus orchestre; un writer unique implémente un changement cohérent.
- **Acceptée**: CONSULT/AUDIT/REVIEW externes read-only; EXECUTE harnessé et sandboxé.
- **Acceptée**: fan-out maximal 4, nesting interdit.
- **Acceptée**: Bash allowlist exacte; tests obligatoires distincts des commandes autorisées.
- **Acceptée**: le verifier recalcule Git; le rapport du worker n’est pas une preuve.
- **Acceptée**: SonarQube est un gate additionnel fail-closed lorsqu’activé.
- **Acceptée**: Neon est optionnel et hors chemin critique.
- **Acceptée**: OpenHands ne sera ajouté qu’après intégration canari de Foundation.
- **Proposition suivante**: programmer le control plane avec Claude Agent SDK après validation live des hooks dans le dépôt cible.
